# Privacy nutrition labels (v1)

**Data not collected.** v1 does not require an account, does not track, and does not send photos to a server.

## Permissions

| Permission | Why |
| --- | --- |
| Photo library (read) | Place existing pictures on pages, collages, and films |
| Photo library (add) | Save exports when the user taps Save |
| Camera (optional) | Take a new page photo |
| Files / music | Optional soundtrack for a film |

Photos are copied into the app sandbox. They leave the device only if the user shares or saves them.

## App Store privacy answers (v1)

- Tracking: No
- Purchase history: No (RevenueCat handles IAP inside the store account; we do not collect a name or email)
- Contact info: No
- User content (photos): Not collected by us. Processed on device.
- Identifiers: None required
